# Feline Brothers 🐱🐯

Two-player co-op HTML canvas platformer. No build step, no dependencies — one `index.html`.

**Play:** https://korjavin.github.io/brothersgame/

| | Cat | Tiger |
|---|---|---|
| Keys | `W` `A` `D` | `↑` `←` `→` |
| Trait | double jump, fast | smashes crates, heavy |

Both brothers must reach the door. Stand on each other's shoulders to reach high ledges.
`R` restarts the level. Collect the fish.
